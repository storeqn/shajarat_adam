# حلويات شجرة آدم

نسخة من واجهة منيو الياسري بنفس بنية HTML/CSS/JS والسلة والبحث والطلب والخريطة. استبدلت هوية المطعم ومنعت الاتصال برقم واتساب الياسري أو Google Sheet الخاص به. يجب إعداد منتجات الحلويات وأسعارها ورقم واتساب المتجر قبل تفعيل الطلبات. لا تحتاج R2 أو D1 للنشر الثابت.

## البناء
`npm run build` → `dist` (Cloudflare Pages).
