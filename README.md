# حلويات شجرة آدم — Shajarat Adam Sweets

نسخة تأسيسية قيد التطوير، **ليست اكتمالاً لجميع المواصفات ولا جاهزة للإطلاق التجاري**.

## المنفذ
React/TypeScript، واجهة عربية متجاوبة، بحث ومفضلة وسلة محلية، خيارات وأسعار مستقلة، نافذة تفاصيل، إدارة منتجات وأقسام ومناطق توصيل وإعدادات وطلبات، حفظ رابط HTTPS للصورة الرئيسية، تخزين D1، إعادة تسعير الطلبات على الخادم، رسالة واتساب، معرف طلب فريد لمنع تكرار الإرسال، حساب إدارة بكلمة مرور PBKDF2 وجلسة HttpOnly/Secure وSameSite وحماية Origin وتحديد معدل الطلبات. المتجر مغلق افتراضياً ولا توجد أسعار أو منتجات وهمية.

## تحديث لوحة الإدارة — 26 أكتوبر 2026
أضيفت إمكانية تعديل اسم القسم وإخفائه وإظهاره، وتعديل اسم منطقة التوصيل وأجرتها وإخفائها، وإخفاء المنتجات وإظهارها دون حذف بياناتها. أضيف أيضاً حقل اختياري لكتابة عبارة على الكيك أو رسالة الهدية لكل صنف في السلة، وتُحفظ العبارة ضمن الطلب ورسالة واتساب. هذه ليست واجهة مصمم هدايا مرئي كامل. وأضيف كذلك تصدير آخر 5000 طلب إلى CSV من صفحة الطلبات للإدارة حصراً. هذه التغييرات غير مختبرة ببناء إنتاجي بعد، ولا تعني جاهزية المتجر للإطلاق.\n\n## ما لم ينفذ بعد
مصمم الهدايا، تخصيص الكيك، الكوبونات والعروض المؤقتة، الحجز المؤقت للطلب قبل اعتماد الإدارة، صور متعددة ومصغرات، حذف وترتيب الأقسام والمناطق (يتوفر الآن تعديل الاسم والإخفاء والإظهار)، الأدوار والصلاحيات، النسخ الاحتياطي والاستيراد، الفواتير وCSV، شرائح الرئيسية والمناسبات، SEO للمنتج على الخادم وروابط مستقلة وQR، فلاتر متقدمة وإعادة الطلب، اختبارات المتصفح والتكامل الكاملة وتحسين الوصول للنافذة. الأسعار المعروضة أولية لحين التحقق على الخادم؛ الطلب المبدئي لا يحجز المخزون؛ اعتماد الطلب من الإدارة يخصم المخزون بشكل ذري بواسطة ترحيل 0002، والإلغاء قبل الاكتمال يعيده. الطلبات القديمة التي لا تحمل معرّف خيار المنتج تحتاج مراجعة يدوية قبل اعتمادها. لا تفعّل الطلبات التجارية قبل استكمال ذلك.

## تثبيت التطبيق PWA\nأضيف manifest وأيقونة وخدمة عمل محدودة لتجربة التثبيت والشاشة الأساسية دون اتصال. بيانات المتجر والطلبات والإدارة تحتاج اتصالاً بالخادم ولا تحفظ محلياً عبر الخدمة. يلزم اختبار عملي على iPhone وAndroid بعد النشر عبر HTTPS.\n\n## تحديث المخزون\nنفّذ الترحيل 0002 قبل تفعيل الطلبات. قبول الطلب بحالة «تم الاستلام من المحل» يحجز المخزون، والإلغاء يعيد الكمية. تغيير حالة الطلب قبل قبوله مباشرةً إلى «مكتمل» مرفوض. لم تُنفّذ اختبارات التكامل على Cloudflare بعد.\n\n## تشغيل محلي
Node 22.13+ (Node 24 موصى به).
```bash
npm ci
npm test
npm run build
npx wrangler d1 migrations apply shajarat-adam --local
npm run preview
```
`npm run dev` يشغّل الواجهة فقط؛ API يحتاج Pages dev بعد البناء. جلسة الإدارة Secure: استخدم HTTPS محلياً إذا لم يقبل المتصفح كوكي localhost:
```bash
npx wrangler pages dev dist --local-protocol https
```

## الصور
أصبح حقل صورة المنتج يقبل رابط HTTPS مباشر بدلاً من رفع الملف؛ لا حاجة إلى اشتراك R2. استخدم رابط صورة عام مباشر ومستقر من استضافة صور موثوقة. روابط Google Drive الخاصة أو صفحات مشاركة الصور قد لا تعمل.\n\n## Cloudflare
```bash
npx wrangler login
npx wrangler d1 create shajarat-adam
```
انسخ database_id الناتج إلى wrangler.toml مكان REPLACE_WITH_D1_ID. الربط DB لقاعدة D1 فقط؛ صور المنتجات تُعرض من روابط HTTPS عامة ولا تحتاج R2. لا تضع مفاتيح في الواجهة.
```bash
npx wrangler d1 migrations apply shajarat-adam --remote
```

## إنشاء المدير الأول
لا توجد كلمة مرور افتراضية. في Bash اقرأ كلمة المرور سرياً، ثم أنشئ SQL مؤقتاً خارج المستودع (يتضمن تجزئة فقط):
```bash
read -s -p 'Admin password (14+ characters): ' ADMIN_PASSWORD
export ADMIN_PASSWORD
node scripts/admin.mjs owner@example.com > /tmp/shajarat-admin.sql
unset ADMIN_PASSWORD
npx wrangler d1 execute shajarat-adam --remote --file=/tmp/shajarat-admin.sql
rm /tmp/shajarat-admin.sql
```
للمحلي استبدل --remote بـ --local. افتح /admin. من الإعدادات ضع واتساب دولياً دون +، والعنوان والساعات؛ أضف أقساماً ومنتجات وأوزاناً بأسعارك الحقيقية. لا تفتح استقبال الطلبات قبل استكمال المتطلبات الناقصة.

## النشر
```bash
npm run build
npx wrangler pages project create shajarat-adam --production-branch main
npx wrangler pages deploy dist --project-name shajarat-adam
```
أو اربط مستودع storeqn/shajarat_adam بمشروع Pages؛ البناء npm run build والمخرج dist، واضبط DB للإنتاج والمعاينة. لا تستخدم GitHub Pages لأنه لا يشغل D1 وFunctions. المرجع: https://developers.cloudflare.com/pages/functions/bindings/

## التحديث
احتفظ بملف القفل. شغّل npm ci وnpm test وnpm run build، طبّق الترحيلات الجديدة ثم انشر. لا تعدّل الترحيلات المطبقة؛ أضف ترحيلاً جديداً. احفظ نسخة D1 قبل التغييرات الإنتاجية.

## حدود الأمان والتحقق
صور المنتجات روابط HTTPS عامة بحد أقصى 2048 حرفاً؛ تأكد من موثوقية المضيف واستمرار الرابط. لا توجد صلاحيات متعددة أو تدقيق أمني مستقل. حد تسجيل الدخول الحالي 30 طلباً/دقيقة/IP، ويجب تقويته حسب الحمل. الطلب يحتفظ بلقطة السعر ولا تُكشف بيانات العملاء إلا للإدارة. فتح واتساب لا يغيّر الحالة ولا يمسح السلة.
