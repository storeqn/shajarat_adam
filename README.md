# حلويات شجرة آدم

منيو عربي سريع وطلبات واتساب، بواجهة HTML/CSS/JavaScript دون مكتبات واجهة أو خطوط خارجية. لوحة الإدارة مفتوحة دون تسجيل دخول أو كلمة مرور بناءً على طلب المالك.

## تشغيل وفحص

- `npm test`: اختبارات البيانات والأوزان والمواعيد وعقد الخادم.
- `npm run build`: إنشاء `dist` للنشر على Cloudflare Pages. يعمل دون اتصال ولا يضم الخادم أو الاختبارات.
- `npm run test:browser`: اختبارات Chromium ببيانات وخادم وهميين؛ تحتاج تثبيت Playwright وChromium (`npm install --no-save playwright@1.56.1` ثم `npx playwright install chromium`). لا تكتب هذه الاختبارات إلى المتجر الحقيقي.
- `python -m http.server 8000`: معاينة محلية. افتح `/` أو `/admin.html`.
- `npm run refresh-menu`: تحديث نسخة المنتجات العامة المضمنة من المصدر الحالي. لا يغيّر بيانات المتجر.

مسار الإدارة: `/admin.html`. رقم واتساب ومواعيد العمل ومناطق التوصيل قابلة للتعديل من تبويب «المتجر والتوصيل». لا توجد أسعار توصيل أو مكونات أو ساعات عمل مختلقة؛ يملؤها المالك.

## الميزات المتاحة مع الربط الحالي

- استعادة السلة، روابط مباشرة للمنتج والوزن، بحث ومفضلة وعروض وصور محلية محسنة.
- معلومات المكونات والحساسية والحفظ، النكهات والتغليف وإهداء برسوم اختيارية.
- موعد الطلب، عنوان أو موقع للتوصيل، مناطق وأجور، تحقق من التوافر، رقم مرجعي ورسالة واتساب.
- معرف ثابت لمجموعة المنتج مع معرف مستقل لكل وزن؛ تغيير الوزن لا يحذف المعرّف.
- تعديل جماعي للأسعار والتوافر، ترتيب بالأسهم أو السحب، سلة محذوفات قابلة للاسترجاع.
- عشر نسخ احتياطية وسجل تعديلات على جهاز المدير مع تصدير واستيراد JSON.
- أيقونات تثبيت، تخزين هيكل الموقع دون اتصال، ومشاركة وبيانات منظمة.

يتم تخزين الحقول الجديدة بشكل متوافق داخل لاحقة `[adam-v3:BASE64]` في عمود الوصف الموجود. الواجهة تفصل الوصف عن البيانات الإضافية؛ لا تحذف اللاحقة عند التعديل المباشر في Google Sheet. الأعمدة A–K الحالية لا تتغير. المجموعة القديمة تُربط أول مرة بحسب الاسم والقسم والصورة، وتكتسب UUID ثابتاً عند الحفظ. لا تستخدِم لوحة الإدارة القديمة لتعديل الوصف بعد الانتقال.

النسخة القديمة من API تحفظ الأوزان بالتتابع؛ لا تحذف الواجهة أي صف نهائياً، وتأخذ نسخة قبل التعديل. عند انقطاع الحفظ قد يُحفظ جزء من الأوزان؛ تظهر رسالة خطأ وتُحدَّث القائمة. التحديث التالي يدعم الحفظ كوحدة مع استرجاع النسخة عند فشل الكتابة ومراجعة التغييرات المتزامنة.

## تفعيل الخادم v3 — خطوة في حساب Google للمالك

**رفع صور الهاتف، سجل الطلبات المشترك وحالاتها، النسخ المركزية وسجل التعديلات المركزي تحتاج تحديث Apps Script.** ملفات GitHub وحدها لا تغيّر مشروع Apps Script المنشور. حتى التفعيل تعمل الميزات الأخرى عبر API القديم، وتوضح لوحة الإدارة ما يحتاج التفعيل.

1. افتح Google Sheet الحالي ثم «الإضافات → Apps Script» وافتح مشروع الويب المرتبط بالرابط الموجود في `store.js`.
2. احتفظ بنسخة من كود المشروع القديم ونسخة من الشيت.
3. استبدل الكود بمحتوى `backend/Code.gs` واضبط `appsscript.json` من الملف المرفق عند الحاجة. معرّف الشيت الحالي مضبوط بالفعل.
4. شغّل `setup` من المحرر ووافق على صلاحيات Sheets وDrive. ينشئ التبويبات والمجلدات الناقصة دون مسح المنتجات.
5. من «نشر → إدارة عمليات النشر → تعديل»، اختر **إصداراً جديداً لنفس عملية النشر**، التنفيذ بصفتك والوصول «أي شخص»؛ لا تغيّر رابط `/exec` الموجود. لا يوجد تسجيل دخول للمستخدمين.
6. افتح `/admin.html` وحدّث الصفحة. يتعرف الموقع تلقائياً على `action=capabilities` بالإصدار 3. جرّب حفظ منتج واختيار صورة وتسجيل طلب تجريبي.

إذا أنشأت عملية نشر جديدة برابط مختلف، غيّر `API` في `store.js` وأعد النشر. ملف الخادم غير موجود ضمن `dist` ولا يُنفذ على Cloudflare.

## البيانات والطلبات

- المنتجات: تبويب «المنتجات»، الأعمدة `id,name,price,category,description,image,badge,active,old_price,offer,weight` بالترتيب الحالي. إعدادات المتجر صف محجوز بقسم `__settings__` يستثنى من العرض.
- الطلبات بعد تفعيل v3: تبويب «الطلبات». الخادم يعيد حساب المجاميع ويتحقق من الأصناف والتوافر والمواعيد. حالات: بانتظار تأكيد المتجر، مقبول، قيد التجهيز، جاهز، مكتمل، ملغي.
- رقم المرجع ورسالة واتساب وحدهما لا يثبتان إرسال الرسالة أو قبول الطلب أو الدفع. السجل المحلي يوصف كمسودة؛ بعد حفظ الخادم يوصف بانتظار التأكيد. تبويب الإدارة يعرض الإيراد من الطلبات الموسومة «مكتمل» فقط.
- سجل المشاهدات ومحاولات الطلب محلي على الجهاز، وبعد تفعيل الخادم تُجمع مشاهدات تفاصيل المنتجات ومحاولات الطلب مركزياً وتظهر أكثر المنتجات مشاهدة خلال 30 يوماً. إحصاءات الطلبات المكتملة تأتي من سجل الحالات، ولا تُعد محاولات واتساب مبيعات مؤكدة.
- النسخ المركزية: ملفات JSON خاصة في Drive، آخر 30 نسخة. سجل التعديلات المركزي في تبويب مستقل، والاسم «إدارة المتجر» لأن الدخول دون حساب.
- صور الهاتف: تُصغّر إلى حد أقصى 1000 بكسل وترفع إلى Drive وتتاح للعرض برابط؛ الصور صور منتجات عامة.
- عدم وجود كلمة مرور يعني أن أي شخص يعرف نقاط الإدارة يستطيع استخدامها. لا تنشر تبويبات الطلبات والنسخ والسجل كجداول عامة؛ يظل API الإداري مفتوحاً كما طلب المالك.

## السرعة والتخزين

تظهر نسخة المنتجات العامة المضمنة أو آخر نسخة محفوظة فوراً، ثم يستدعى مصدر واحد ويُستخدم Google Sheet احتياطياً عند فشله فقط. لا يُسمح بإرسال الطلب حتى تأكيد البيانات الحية؛ وبعد مرور دقيقتين يُطلب تحديثها ومراجعة السلة. لا يخزن Service Worker أي استجابة Google أو بيانات طلبات؛ يدعم الملفات المحلية للتصفح دون اتصال فقط.

الصورة الرئيسية نحو 123 كيلوبايت بدلاً من 189، و17 صورة من المنتجات الحالية حُوّلت إلى WebP محلية، من نحو 3.43 ميغابايت إلى 388 كيلوبايت إجمالاً. تعرض الصور عند الحاجة وبأبعاد ثابتة لتخفيف قفز التخطيط. `data/image-map.js` يربط الرابط الأصلي بالنسخة المحسنة؛ أي صورة جديدة تستخدم رابطها حتى تحسين نسخة محلية منها. حدّث الصور المحسنة عند تغيير محتوى رابط ثابت.

أوامر البناء تنسخ الملفات ولا تتطلب تنزيل المنتجات أو حزم واجهة. ملف `_headers` يضبط التخزين في Cloudflare؛ يطبق GitHub Pages قواعده الخاصة. اختبارات GitHub Actions تتحقق من المنطق والبناء والمتصفح قبل تقييم النشر، ولا تكتب إلى بيانات المتجر.

## الاسترجاع

قبل استيراد نسخة يأخذ النظام نسخة محلية من الحالة الحالية. النسخة المستوردة تعيد المنتجات الموجودة، وتُنقل الخيارات غير الموجودة فيها إلى سلة المحذوفات. من «النسخ والسجل» يمكن تنزيل نسخة ثم استيرادها، أو استرجاع منتج محذوف. احتفظ بنسخة خارج المتصفح لأن مسح بيانات المتصفح يمسح النسخ والسجل المحليين.

## صور متعددة للمنتج

من لوحة الإدارة افتح المنتج، واختر عدة صور من الهاتف أو أضف روابط HTTPS، حتى 8 صور. الأولى هي الرئيسية ويمكن تعيين أي صورة رئيسية أو تغيير الترتيب أو حذف صورة قبل حفظ المنتج. تُصغّر صور الهاتف وتُرفع بالتتابع لتخفيف استهلاك الذاكرة. عند فشل رفع صورة تبقى الروابط التي نجح رفعها داخل نموذج التعديل لتجنب إعادة رفعها عند المحاولة التالية.

المعرض يظهر داخل تفاصيل المنتج، ويدعم الصور المصغرة وأزرار التنقل والسحب على الهاتف وأسهم لوحة المفاتيح. بطاقات المنيو تحمل الصورة الرئيسية فقط؛ صور Drive المصغرة تستخدم حجماً أصغر. الصور القديمة ذات الرابط الواحد تستمر في العمل. تُحفظ الصور الإضافية داخل `meta.images` باستخدام عقد الوصف الحالي؛ لا يحتاج الخادم v3 إلى تعديل أو نشر جديد، ولا تُحذف ملفات Drive الأصلية عند إزالة صورة من المنتج.


### ثبات عرض الهاتف والتنقل من البطاقة

الصفحة ولوحة الإدارة تستخدمان مقياس عرض ثابتاً حسب طلب المالك، مع منع إيماءات تكبير الصفحة في المتصفحات الداعمة، وحجم 16 بكسل لحقول الإدخال لمنع التكبير التلقائي عند الكتابة. أزيل تغيير ارتفاع البطاقات الناتج عن التخطيط المؤجل. المنتج متعدد الصور يعرض عداداً وأسهم يمين ويسار في بطاقة المنيو نفسها، مع دعم السحب وفتح المعرض بالنقر على الصورة؛ الأسهم تظهر أيضاً فوق الصورة الكبيرة داخل التفاصيل.
